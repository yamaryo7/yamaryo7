# 馬券帳

競馬の収支と家計簿を1つにまとめたデスクトップアプリ（Windows 11／macOS、13インチノート向け）。
馬券を1回入力すると、競馬収支（券種別・レース別・期間別の的中率と回収率）と家計簿（購入＝支出、払戻＝収入）の両方に反映される。

技術: Tauri 2 + React + TypeScript + SQLite（tauri-plugin-sql）。ネットワーク機能なし。

## 起動方法

```bash
cd bakencho
npm install

npm test             # 指標ロジック・点数計算・取り込み・SQLite保存のユニットテスト
npm run dev          # ブラウザで画面だけ確認（http://localhost:1420、保存先は localStorage）
npm run tauri dev    # デスクトップアプリとして起動（保存先は SQLite）
npm run tauri build  # インストーラ作成（Windows: .msi/.exe、macOS: .app/.dmg）
```

前提: Node.js 20以上、Rust（stable）。Windows は WebView2（Windows 11 は標準搭載）、macOS は Xcode Command Line Tools。
Windows／macOS のインストーラは、GitHub の Actions タブ →「馬券帳 インストーラ作成」→ Run workflow でも作れる（成果物は実行結果の Artifacts）。
macOS は未署名のため、初回起動は Finder で右クリック →「開く」。

## 確認手順（フェーズ1〜3）

1. 起動するとダッシュボード。「サンプルデータを入れる」で過去8か月分の馬券と家計簿が入る。
2. 直近の土曜の「中山12R 計算例のレース」が要件書の計算例（投資1,300円・払戻1,240円・回収率95.4%・収支−60円、馬券的中率33.3%・レース的中率100%）になっていることを、レース明細で行を開いて確認する。
3. 上部の期間（今月／先月／今年／全期間／月を指定／期間指定）を切り替え、KPI・券種別・グラフが同時に変わることを確認する。
4. 右パネルで 券種→買い方→買い目→点数→1点金額 を Tab で進めて入力。Enter で票の行が増え、Ctrl+Enter（Mac は ⌘+Enter）で保存。保存後は同じ開催日・競馬場のまま次のレース番号に進む。ボックス・流し・フォーメーションは買い目から点数が自動計算される（手で上書き可、「自動」で戻す）。
5. レース明細で払戻セルに金額を打つと、その場で結果バッジ・KPI・左下の「今月の収支」が変わる（空欄＝未確定、0＝不的中）。
6. 家計簿で、競馬の行が開催日ごとに「馬券購入」「払戻」として薄い色で自動表示され、削除できないこと、右パネルが家計入力に切り替わることを確認する。
7. 分析で 券種／買い方／競馬場／月／曜日 のタブを切り替える。
8. 設定・データで JSON／CSV の書き出し、JSON からの復元、Excel/CSV 取り込み（列の対応づけ → 件数と重複候補の確認 → 取り込み）、費目の編集を試す。

## 決めたこと（要件に書かれていなかった点）

| 項目 | 決めた内容 |
| --- | --- |
| レースの的中 | 的中票があっても未確定の票が残っていれば「未確定」（要件の文言どおり）。レース的中率の分母は確定レースのみ |
| 未確定の票 | 投資には入れ、払戻・的中率には入れない |
| 同じ開催日・競馬場・レース番号で保存 | 既存のレースに票を追加する（入力パネルに「登録済みのレースに追加します」と出る） |
| 競馬場 | 中央10場＋主な地方競馬場＋海外・その他を候補に出し、自由入力も可 |
| 買い目の書式 | 通常 `3-7`／`3→7`、ボックス `3,7,12`、流し `軸>相手`（例 `3>1,5,8`、三連系の2頭軸 `3,7>1,5,8`）、フォーメーション `1,2/1,2,5/1,2,5,8`、WIN5 `1,2/5/3,8/11/4,6`。全角でも可 |
| 取り込みでオッズ列を使う場合 | 払戻 ＝ オッズ × 1点金額（的中は1点とみなす） |
| 取り込みの重複候補 | 既定は「取り込まない」。チェックを外せば取り込む |
| 家計簿の競馬行の日付 | 開催日（購入日ではない） |
| データの保存先 | OSのアプリ設定フォルダの `bakencho.db`（Windows: `%APPDATA%\jp.bakencho.app`、macOS: `~/Library/Application Support/jp.bakencho.app`）。設定画面に表示 |
| プロトタイプ（ブラウザ版）のJSON | そのまま復元できる。購入額は「1点＝総額、1点」として取り込み、競馬の家計行は二重計上を避けるため取り込まない |

## 構成

```
src/domain/   純粋関数（指標・期間・点数計算・家計簿の導出・CSV・バックアップ・Excel取り込み）と *.test.ts
src/db/       保存先（sqliteRepo: Tauri上の SQLite、browserRepo: ブラウザ確認用）
src/state/    画面全体の状態（変更は先に画面へ反映し、続けて保存）
src/pages/    ダッシュボード／レース明細／家計簿／分析／設定・データ／取り込みウィザード
src/panels/   右ペイン（馬券入力・家計入力）
src-tauri/    Tauri（Rust）。migrations/0001_init.sql がスキーマ
```

ショートカット: Ctrl/⌘+1〜5 で画面切替、開催日欄で ↑↓ 1日・PageUp/PageDown 1週間・t で今日、レース明細の払戻セルで Enter 次のセル。
